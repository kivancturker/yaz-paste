# How to answer

- Answer with **unified diffs** against the files shown (`--- a/path` / `+++ b/path`), one per file, with enough context lines to apply them.
- For new files, give the full file content with its path.
- Keep explanations short: a few sentences before the diffs, no restating of the code.
- If something needed for the change isn't in the context, say which file or information is missing instead of guessing.
